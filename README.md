El Contenedor: w-60 m-auto
Define un tamaño compacto y fijo para la calculadora, aplicando márgenes automáticos que la mantienen perfectamente centrada en la pantalla, evitando que el diseño se disperse en monitores anchos.

Las Entradas: w-full
Extiende los campos de texto para que abarquen todo el ancho interno del contenedor. Esto crea una estructura uniforme y profesional, asegurando que los cuadros de escritura se alineen con los bordes del panel.

El Botón: bg-blue-500
Aplica un tono azul vibrante que resalta la función de ejecución. Su propósito es generar un contraste visual inmediato para que el usuario identifique rápidamente dónde debe hacer clic para calcular.

El Resultado: text-center
Ubica el texto del resultado en el eje central de la tarjeta. Esta alineación elimina la asimetría y garantiza que el dato final sea el foco visual del componente, manteniendo el orden estético.
